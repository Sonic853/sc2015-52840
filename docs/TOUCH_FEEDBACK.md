# 修订号20/21：右板滑动与Lizard滚轮触觉

修订号21将Switch右板滑动接入同一反馈设置；修订号20已支持Xbox、PS5和Lizard。配置格式和强度参数共用，无需为Switch重新保存。

## 行为

|模式/输入|反馈|
|---|---|
|Xbox / PS5 / Switch / Lizard右触控板滑动|右板短单脉冲；首次落指及静止触摸不持续震动；Switch需修订号21|
|Lizard左板产生滚轮|每次成功提交的**非零USB滚轮报告**对应一次左板短单脉冲|
|Steam原生模式|仍逐条转发主机原始8F，参数不被本设置缩放|

一次滚轮报告可能包含多个刻度，例如`wheel=-6`仍反馈一次，而不是人为补发六次。只有USB接受报告后才排入对应脉冲；端点忙或发送失败不会提前震动。射频反馈队列没有容量时，暂不把wheel放入USB报告，保留待发滚轮，同时继续处理鼠标移动和按钮。0强度关闭对应反馈，也解除滚轮对反馈容量的等待。

右板按连续已认证输入相对上次事件锚点的净位移判断运动：`abs(dx)+abs(dy)>=128`原始坐标单位产生待发事件，最多每20ms一次（50Hz）。门槛内的小幅来回抖动不会累积成脉冲。快速移动合并为最新事件；抬手、旧触摸锚点超过100ms、换会话、模式切换和USB生命周期重置清除运动状态。

## 与Steam强度一致的依据

现有实物Steam触控捕获冻结在`tests/haptic_arrivals.json`，单脉冲参数为：

```text
右板：8f 08 00 64 00 00 00 01 00 00  → 宽度100µs
左板：8f 08 01 15 02 00 00 01 00 00  → 宽度533µs
```

新反馈默认使用相同字段：`8F`、右side0/左side1、间隔0、次数1、gain0。网页调节的是该脉冲宽度，范围**0–1000µs**，0为关闭；不是额外使用60ms游戏震动波形。相同参数不等于已经实测完全相同的主观强度或触觉频率，仍受手柄和发送节奏影响。

接收器不能读取Steam配置文件，也没有已证实的“读取Steam强度百分比”接口。因此提供显式的**读取并填入最近Steam参数**功能：

1. 在Steam模式连接手柄，让Steam运行并滑动触控板。
2. 打开网页21.0，连接接收器配置接口，点击“读取并填入最近Steam参数”。
3. 网页读取本次USB会话中、最近同一无线槽/会话的已接受单脉冲宽度。只复制观察到的一侧，另一侧保持当前表单值。
4. 点击“保存反馈强度”，再进入Xbox/PS5/Switch/Lizard使用。

观察条件为完整`8f 08`、side0/1、宽度1–1000µs、间隔0、次数1、gain0；其他波形继续原样转发但不被当作触控基准。仅凭这些字段不能识别发送进程，所以准确含义是**Steam模式下主机发送的同类脉冲**。未观察到脉冲不能推断Steam已将强度设为0。观察缓存不写Flash，断连/换会话/USB reset后不拿旧参数冒充当前参数。

## 网页调节

使用能力修订号20及更新（Switch需21），在网页21.0的 **“触控板滑动与滚轮震动”** 面板：

- “右触控板滑动强度”：共用于Xbox、PS5、Switch、Lizard右板。
- “Lizard左板滚轮强度”：只控制Lizard滚轮反馈。
- “读取反馈配置”：重新载入已保存值。
- “读取并填入最近Steam参数”：读取观察缓存并填表，**不会自动保存**。
- “填入Steam基准强度”：填入右100/左533，**不会自动保存**。
- “保存反馈强度”：写入配置页并核验回读，重启/重新上电保留。

需先用A＋Steam开机返回Steam才有配置接口。修改反馈与修改游戏手柄映射使用独立token，彼此不覆盖；旧网页保存24字节映射也会保留新反馈值。中英文切换保留尚未保存的滑块值。游戏主机的双通道震动仍按原幅度转换，不受此触控设置缩放。

Switch的本地触控反馈独立于主机子命令`0x48`的游戏震动开关；关闭游戏震动不会撤销本地滑动反馈，要关闭右板反馈请将网页右板强度设为0。左板在Switch仍作为十字键，不产生Lizard专用滚轮反馈。

## 队列与停止规则

内部触控脉冲与游戏rumble、主机原始8F分别标记。每槽最多排两条尚未加密的触控反馈；普通主机队列容量仍为12片。内部反馈计入FC的`admitted`，不伪造USB `haptic_received/haptic_admitted`。

游戏rumble停止不清除触控脉冲，触控取消也不清除游戏rumble或主机原始8F。未加密触控脉冲在队头过期100ms时丢弃；断连、导入、USB reset/suspend、owner变化和右板抬手会撤销相应未加密反馈。已加密lane持有CCM counter，**不删除、替换或跳过**，所以已在途脉冲仍可能稍后到达。单个物理触控执行器上的游戏震动和触控脉冲按链路次序执行，不宣称混合波形可同时独立播放。

## 配置与协议兼容

Flash配置记录升级为 **SCXM v3，56字节**：原24字节映射仍在12..35；last/once在36/37；right_us在38..39、left_us在40..41；42..47保留0；CRC32在48..51，最后提交字在52..55。仍使用原双页，不移动绑定页。

读取旧v1/v2的48字节记录时，只读旧格式范围，保留映射和启动策略，新反馈默认右100/左533；下一次保存或启动选择写入会生成v3。旧固件不认识v3，降级时可能采用仍有效的旧页或默认配置，不能期望向前兼容。

FE v1原24字节映射和其token不变，修订号20增加回复尾部：

|偏移（64字节Feature起点）|内容|
|---|---|
|36|反馈schema=1|
|37|观察掩码：bit0右、bit1左|
|38..39 / 40..41|已保存right_us / left_us，LE16|
|42..45|38..41四字节的CRC32，反馈写入token|
|46..47 / 48..49|最近观察的右/左宽度；未观察一侧为0|
|50|观察来源槽0..3；无有效观察为255|

新写入：`FE 09 02 <token LE32> <right_us LE16> <left_us LE16>`。范围、过期token、busy和Flash失败沿用FE错误状态；只改反馈字段，保留最新映射。网页仅在修订号>=20且成功解析扩展后开放写入。

## 验证

原生测试覆盖Steam脉冲字节、首次落指/静止/小位移门槛/20ms限频/回卷、四种翻译模式与Steam原生隔离、0强度和自定义宽度、v1/v2升级、v3破坏/撕裂拒绝、独立token和失败保存。生产CCM链路验证左右脉冲解密、Switch游戏震动未启用或收到关闭命令时本地触控仍有效、rumble/host8F取消隔离、已加密lane不变、明文超时、USB忙时不提前震动、射频满时指针继续/滚轮延后且只生成一条反馈、Steam观察失效和多脉冲不误学习。

网页回归覆盖保存/重启、Steam参数显式复制、未观察侧保留、旧固件拒绝、校验损坏和中英文表单保留。双板产物及当前测试计数见 [VERIFICATION.md](VERIFICATION.md)。本轮尚未实物刷入和确认触感。
