# 修订号19：Lizard键盘/鼠标模式与完整映射

修订号20新增右板滑动反馈与左板滚轮反馈：每次成功提交非零USB滚轮报告反馈一次，强度可在网页20.0独立调节并保存。射频反馈容量不足时暂缓滚轮，指针/按键继续；详见 [TOUCH_FEEDBACK.md](TOUCH_FEEDBACK.md)。按键表沿用本页。

## 进入与退出

1. 接收器运行**修订号19或更新**，使用已经保存绑定的2015版Steam Controller。
2. 同时按住 **左背键＋右背键＋Steam键开机**。恢复无线连接后继续保持约300ms，然后将三键全部松开。
3. 接收器保存启动选择、断开USB、等待至少60ms后整机重启，枚举为 **SC2015 Lizard Keyboard/Mouse**（`28de:1144`）。等待手柄恢复连接即可使用。
4. **A＋Steam开机返回Steam模式**，再使用网页配对、修改配置或进入UF2。也可在Steam网页19.0选择“Lizard 键盘/鼠标”；实际切换要求设备修订号>=19。

组合只在新无线会话前3秒识别，要求持续的新鲜认证输入；相邻输入超过150ms会重新计时。新配对尚未保存时不切换。三键应同时按住，避免先保持单背＋Steam超过300ms而进入Xbox或PS5。

A返回优先；双背＋Steam明确选择Lizard；LB混合背键的选择组合被忽略。模式组合消费后，必须完全松开组合里的键才能输出普通输入，USB合成中性报告不会代替物理松键。

默认一次性模式在启动时消费，完成启动后下次重新上电回Steam。可在Steam网页保存“记住输入模式”以保持Lizard；保存后、首次消费前断电，下次启动仍执行未消费的选择。持久化失败不切换。模式值4沿用FD/FE v1；修订号19使用48字节记录v2，20起增加触控强度并写入56字节v3、兼容读取旧记录。降级到不认识模式值或记录版本的旧固件可能采用旧页或默认配置。

## 触控板细节

### 左板画圈滚轮

- 以触控板中心为圆心，手指沿中心外围画圈。半径低于原始坐标6000时暂停并重置角度锚点，穿过中心不会跳滚。
- 一整圈名义**24个HID滚轮刻度**；使用整数角度近似，主机的“每次滚动行数”仍影响实际页面距离。
- 相邻有效角度增量超过90°视为坐标跳变并重新定位，不产生大段滚动。左板坐标超过200ms无新采样也重新定位。
- 抬手/重新触摸不延续上一段角度余量；没有惯性滚动。
- SC2015左板和物理摇杆共用坐标字段。只有实际左板样本更新角度；标记两者仍活动的摇杆包不会被误当作左板坐标。

### 右板指针

- 将触摸位置差转换为鼠标相对位移，原始坐标128单位对应1个HID移动单位，保留不足1单位的余量；最终指针速度还受操作系统设置影响。
- 首次触摸只定位，抬手后再次触摸不跳到旧位置；无OpenPuck式滑行惯性。
- 单次待发移动限制在每轴±127，待发滚轮限制±15，避免USB长期忙时堆积大段旧运动；超过容量的部分被截断。

## USB与输入来源

独立单HID键盘/鼠标，不暴露Steam游戏手柄或配置vendor HID。复用已审计的桌面描述符：Report ID1为8字节键盘payload，ID2为4字节鼠标payload（按键、X、Y、wheel）；IN端点最大9字节、2ms轮询。Boot模式只发送8字节键盘，丢弃在Boot期间收到的鼠标位移。

一个Lizard USB桌面设备使用一个新鲜无线owner，其余槽不抢占。每250ms无新输入释放全部按键和按钮并清除运动；摇杆坐标单独200ms过期。断连、会话变化、USB reset/resume及模式切换清除历史；挂起期间不发送，也不积存鼠标运动。超过六个不同普通键同时按下使用标准键盘ErrorRollOver，Ctrl/Alt等修饰键独立。

键盘和鼠标共享一个端点：两者都待发时交替处理，只有USB接受提交后才退休相对位移和更新已发送状态。原手柄生成的lizard键鼠报告被隔离，避免与接收器本地映射重复。

## 与OpenPuck的对应

参考本地OpenPuck提交`0114623`：

- `OpenPuck/lizard_map.cpp::defaultLizardMap()`：面键、Back/Start、Ctrl/Alt肩键、摇杆方向、触控板点击和Steam快捷键。
- `OpenPuck/mode_lizard.cpp`：相对触控板鼠标、释放与端点发送状态处理。
- 原OpenPuck左板使用Y方向滑动滚轮；本实现按要求替换为**绕中心画圈**。
- 未移植SC2的按钮位或额外L5/R5、右摇杆；使用SC2015原始按钮与复用坐标。采用固定单owner和独立桌面USB布局，未复制OpenPuck的多手柄合并、可编辑Lizard绑定表或自动Steam接管。
