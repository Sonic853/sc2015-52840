原版读取范围：当前原版应用固件没有已证实的 USB 绑定密钥导出命令。A1 只提供身份；它不能代替 Flash 转储，应用文件 d0ggle.bin 也不含绑定页。迁移需要原 RF 地址、手柄标识和密钥。导入会替换目标身份及全部绑定，期间请关闭无线手柄；完成后拔下原接收器，再开手柄测试重连。

绑定文件包含密钥，仅在本页内存中处理和本地下载，不上传到 GitHub 或其他服务。诊断 JSON 不包含绑定密钥。

首次使用与问题排查
  • XIAO 需刷入本工程更新后的诊断协议 v2 固件；目标是 S140 7.3.0、应用地址 0x27000 的 XIAO，不是二代 OpenPuck。
  • 保存按钮只对“绑定待保存”槽启用。自动保存仅针对本页开启配对后出现的新待保存连接。
  • 诊断时可先退出 Steam 和命令行工具，避免多个程序交错读写同一接口的 Feature 报告。
  • 部分槽显示“未授权”时，它们不是无线断开；再次授权对应 vendor 接口即可。
  • 绑定页解析复现原固件的启动页选择和同 ID 最新记录查找。原格式没有 CRC，解析不代表转储完整性已验证。
  • 当前工程尚未完成真实 XIAO / 手柄的 RF 互通验证；网页计数可用于后续实物调试。
